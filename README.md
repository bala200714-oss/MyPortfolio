# Bala Murali S Portfolio

A React portfolio website built with Vite.

## Run locally

1. Install Node.js version 18 or newer from https://nodejs.org/.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Build for production

```bash
npm run build
```

## Deploy on Vercel

1. Create a Vercel account at https://vercel.com.
2. Import this repository in Vercel.
3. Use the default settings (Vercel will auto-detect the build settings from `package.json`).
4. Deploy.

The resume file is available at `/resume.txt` and the homepage includes **Download Resume** buttons.
